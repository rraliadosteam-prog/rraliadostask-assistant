RR Tareas

Descargar · editar · usar, sin perder el foco

Qué es: un asistente local para capturar tareas y notas. No pide cuenta, no usa DashWeb automáticamente y guarda la información en este computador.
1

Descargar

  1. Abrí el repositorio: github.com/rraliadosteam-prog/rraliadostask-assistant.
  2. Elegí Code → Download ZIP y descomprimilo.
  3. Instalá Node 24+, pnpm 12+ y Rust estable.
  4. En la carpeta del proyecto ejecutá pnpm install.
  5. Para compilar en Linux: pnpm tauri build --no-bundle.
Si aparece una versión instalable en Releases, descargá el artefacto de tu sistema y verificá su SHA256SUMS.txt.
2

Editar

  1. Hacé un fork o cloná el repositorio.
  2. Creá una rama: feat/mi-cambio.
  3. Editá la interfaz o el dominio; no agregues secretos.
  4. Corré pnpm check antes de compartir.
  5. Subí la rama y abrí un Pull Request con capturas y pasos de prueba.

Regla: no edites directamente main y no compartas backups de trabajo real.

3

Usar

  • Creá o abrí un workspace local.
  • Escribí una tarea o nota; Ctrl/⌘ + Enter guarda.
  • Organizá por estado, prioridad, etiquetas, fecha y checklist.
  • Usá el selector Sistema / Claro / Oscuro según tu pantalla.
  • El estado indica Guardado local.
  • Preparar entrega solo copia un preview; no crea nada en DashWeb.
✓

Privacidad y reporte

Todo queda local: no hay telemetría ni conexión automática. Para reportar un problema, enviá versión, sistema, pasos para reproducir y captura; nunca envíes tokens, credenciales ni el backup de un workspace real.
